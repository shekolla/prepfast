## Bug reports and feature requests

Use the GitHub issue tracker:

- **Bugs** — open a Bug Report issue with the URL, what you expected, and what happened
- **Feature requests** — open a Feature Request issue describing the problem it solves
- **Content corrections** — factual errors, outdated material, typos in topic data

Please search existing issues before opening a new one.

## Security vulnerabilities

Do **not** open a public issue for security vulnerabilities. Follow the process in [SECURITY.md](SECURITY.md) to report privately.

## Questions and discussion

Open a [GitHub Discussion](https://github.com/shekolla/prepfast/discussions) for:

- Questions about how the app works
- Ideas that aren't yet ready to be a feature request
- General feedback

## Response times

This is a solo-maintained open-source project. Expect:

- Bug reports: triaged within a few days
- PRs: reviewed within a week of submission
- Security issues: acknowledged within 72 hours (see SECURITY.md)
